候选日期：2026-10-02。新目录实机验收待处理AutoCAD现场并恢复；标签及Release尚未创建，以下获取方式在最终发布后生效。工程实现来自已通过阶段7验收的提交`8560cd2245b63a7ec36c2b6c815853cab37b3da6`；阶段8只增加版本与冻结文档，不修改计算、Controller、解析、CAD或UI代码。

## 获取与启动

稳定演示使用标签，不依赖开发分支或main的当前状态：

```powershell
git clone --branch v0.1-demo --single-branch https://github.com/maximwong/StructAgent.git StructAgent-demo
Set-Location StructAgent-demo
```

已有仓库可在干净工作区新建演示分支：

```powershell
git fetch origin tag v0.1-demo
git switch -c demo-local v0.1-demo
```

如果当前设备有未提交工作或后台任务，先保留现场并结束任务，在另一目录克隆演示版本。

按[固定环境说明](../demo-deployment.md)准备Windows x64 / Python 3.12.14及11个固定依赖，在本机`.env`配置API。打开AutoCAD 2022，完成许可与脚本加载提示，保持空闲。双击`启动StructAgent.cmd`打开界面，输入要求、确认模板，点击开始。第一次使用新源码路径时，AutoCAD可能再次要求手动确认LISP加载；不能通过关闭安全设置省略这一部署步骤。

演示顺序：A（6m×6m/C30/2.0）、B（5.4m×6m/C30/2.0）、C（6m×6m/C35/3.0）。等待每次“已完成”，检查参数依据、已有校核警告，点击打开对应图纸。缺参数时补充输入后重新运行；失败历史保留，不自动重放CAD。

## 发布制品和校验

最终[GitHub Release](https://github.com/maximwong/StructAgent/releases/tag/v0.1-demo)将提供`StructAgent-v0.1-demo-source.zip`和`SHA256SUMS.txt`。源码ZIP只含冻结提交中的受版本管理文件，不包含`.env`、虚拟环境、运行日志、项目结果或DWG。下载后用`Get-FileHash -Algorithm SHA256`核对对应摘要。

本机另保留`verification/phase-8/release/StructAgent-v0.1-demo-windows-offline.zip`，包含同一源码和已核对的运行时/依赖包；没有API密钥、AutoCAD或本机项目数据。二进制不上传公共Release。使用该包时，解压后从`StructAgent/`按[离线安装说明](../offline-deployment.md)操作，bundle位于同级`../offline-bundle/`。离线安装到`data/runtime/offline-demo`后用以下入口运行UI：

```powershell
.\data\runtime\offline-demo\venv\Scripts\python.exe app.py
```

这个离线环境目录与`.venv-demo`不同，因此使用上述入口。自然语言API仍需网络，每台设备独立配置密钥；AutoCAD单独安装和配置。

本机制品目录中的`release-manifest.json`记录候选提交、源码及本机离线包SHA256、依赖锁摘要和验收概要，作为制品核对依据。本机详细验证在`verification/phase-8/`，不进入源码包。

## 冻结范围

- 完整自然语言→本地校验→通用Controller→Registry→设计Tool→CAD Tool→保存重开核验→UI完成链路。
- 办公楼单向板肋梁教学演示模型：主梁3跨、次梁5跨，模板板厚/截面/支承/恒载；梁纵筋HRB400、板筋和箍筋HPB300；混凝土范围沿用已验证映射。
- 模板确认、缺项澄清、输入证据核对、独立结果目录、失败停止、归属恢复和运行历史。
- 无新增Agent专业分支；新增工程工具仍通过统一Tool/Plugin接口接入。

本版本不扩大计算模型的适用范围。CAD硬挂起/全部模态组合、第二台物理设备、真实云鉴权/限流等未完成验收项保留在[技术债清单](../technical-debt.md)。新目录部署中的加载提示属于必须处理的外部条件，不计为自动化成功。
