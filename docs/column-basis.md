# RC Column v1 工程依据与独立参考

本插件限定为教学、非抗震、静力、理想纯轴压的单根矩形柱。规范语境为GB/T 50010-2010（2024年版）及GB 55008-2021；单位固定mm、kN、kN.m、MPa。输入N是同一组合中已经包含结构重要性系数gamma0的最终轴力设计值；静力范围显式采用gammaRd=1。用户同时声明Mx=My=Vx=Vy=0，并提供组合及覆盖两个主轴的控制有效长度l0的来源。插件不生成或核实源内力和l0，不适用于实际框架柱全项设计。

四筋面积(mm²)：12→452、14→615、16→804、18→1017、20→1256、22→1520、25→1964、28→2463。候选直径按此顺序搜索，仅选择第一个全部检查通过的方案，截面、内力、l0、材料、保护层及箍筋均不调整。失败保留所有尝试与逐项判定。

两方向筋中心距为dim-2(c+dt+d/2)，净距为中心距-d。容量需求钢筋面积为max(0,(N×1000/(0.9phi)-fcA)/fy')；它仅表达容量需求，实际设计还同时满足配筋率和构造检查。数值比较使用严格的<=或>=，验收参考数值误差仅用于测试，不能放宽工程判定。

## 未覆盖范围

稳定系数phi包含轴压稳定影响。v1未实现偏压、附加偏心、偏压二阶效应或框架整体二阶分析；不能据此表述为“所有二阶效应均未考虑”。此外未覆盖抗震、疲劳、环境/耐久/防火保护层、锚固搭接、节点与端部、箍筋弯钩及完整详图、用户源内力或有效长度的分析核实。PASS仅表示本插件声明检查全部通过，不能代替工程全项审查。
