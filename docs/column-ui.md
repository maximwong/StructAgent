# 柱网页使用与验收

阶段16把现有柱Tool接入本机网页。算法范围仍是教学、非抗震、静力、理想纯轴压的固定矩形柱，4根等径角筋与单闭合矩形箍。已有轴压稳定系数检查；不支持偏压、剪力、抗震、自动改截面或完整工程审查。依据和限制见[column-basis.md](column-basis.md)。

## 启动与输入

使用包含阶段16代码的开发分支和固定独立环境，双击根目录`启动StructAgent.cmd`。已运行的旧服务不会自动更新；等待任务结束后在页面点击“退出程序”，再重新启动。若端口被其他程序占用，按[部署说明](demo-deployment.md)处理，不强行结束用户CAD。

在“选择专业”中选择“钢筋混凝土柱（本地教学轴压）”。柱操作无需DeepSeek API配置、AutoCAD或自然语言口令；楼盖云解析与出图仍使用既有配置要求。

填写项目名称，并选择操作模式：

- **设计→独立校核**：完整输入固定截面、材料、有效长度及来源、同一组合内力、箍筋、单位/规范和适用范围。流程通过原Controller执行`design_column`和`check_column_design`。
- **单步校核实际配筋**：完整模型和实际纵筋方案；校核不会重新选筋。FAIL保留实际钢筋和失败项目。
- **单步校核本项目引用**：填写原设计的项目标识、同一单位/规范声明以及已保存柱设计引用。不同时填写模型或实际钢筋。

所有必填工程参数均需用户明确填写。案例按钮是显式加载，不默认填入模板。项目名称用于展示；**项目标识决定引用归属**，按引用校核须复用原标识。名称相同不表示引用可以跨项目使用。

可以导入`demos/column-short.json`、`column-slender.json`、`column-check-fail.json`等完整JSON Envelope。导入保留`project_id`、`tool`、`context`及`parameters`；先验证原数据再填表。材料可选显式强度合法时保留，空白时不生成，冲突时拒绝。文件中的未知字段、字符串数值、布尔数值、重复键、非有限数值和不支持内力不能被静默转换或忽略。导入失败不覆盖当前表单。

## 结果与历史

结果展示实际纵筋、钢筋面积、稳定系数phi、轴压承载力Nu、N/Nu利用率、逐项判定及依据、荷载组合/有效长度来源和未覆盖范围。PASS仅适用于声明检查，不能当作一般框架柱全项合格。

引用校核的“本次请求”只包含引用；“已核验工程输入”展示从有效设计引用核验得到的原模型，包括轴压力及组合来源、有效长度及其来源。FAIL提示给出中文检查名称和实际值与限值，不改变原ToolResult或实际配筋。

柱操作没有CAD、计算书或CAD恢复能力，不能把柱计算完成表述为图纸已生成。返回原始结果/引用损坏或归属不一致时，页面显示不可确认，不自动重算或改写历史终态。

同项目重复执行产生独立运行编号与不可覆盖设计引用；历史记录绑定各自运行。专业切换、刷新或重启不重新执行工具。全部专业共享串行执行保护，运行中不重复提交；退出/恢复操作遵循原服务保护。

在“项目标识筛选”中填写完整project_id，点击“筛选历史”，只列出当前专业下该项目的记录；清空后筛选可恢复全部项目。筛选不覆盖正在填写的工程表单，切换专业会清空筛选，新提交会显示本次结果。运行记录缺失或损坏时不回退到同项目最新记录；页面区分记录无法确认与本机服务断开，并清除此前显示的通过结果。

## 自动验证

在PowerShell中分别执行，不把目录切换和运行命令拼为一行：

```powershell
Set-Location '你的StructAgent目录'
.\.venv-demo\Scripts\python.exe -m unittest tests.test_column_ui tests.test_plugins tests.test_column_workflow tests.test_ui tests.test_report_ui -v
```

完整回归与固定环境检查遵循[协作指引](../AGENTS.md)。阶段16不修改阶段15参考数据；期望值不由被测实现重新生成。
