# 本机操作界面

阶段7提供本机浏览器界面，复用既有Controller、Registry、Tool和Project State，不新增Python依赖。界面只能从本机访问，默认地址`http://127.0.0.1:8765`，无需用户系统或云数据库。

## 启动和使用

1. 按`docs/demo-deployment.md`准备`.venv-demo`环境及本机`.env`，打开AutoCAD 2022并结束启动提示或当前命令。
2. 双击仓库根目录的`启动StructAgent.cmd`。它用固定环境启动后台程序并打开默认浏览器；再次双击会打开已有界面。
3. 填写项目名称和自然语言要求，可用A/B/C按钮填入案例。不要复制PowerShell命令或引号，只输入设计内容。
4. 确认界面列出的办公楼演示模板，点击“开始设计”。参数仍须明确，包括跨度单位、混凝土等级、梁纵筋等级、活荷载及单位。
5. 查看理解/校验、楼盖设计、CAD出图三个步骤。解析通过后显示参数及原文依据，随后显示工具日志、设计摘要和校核警告。
6. 只有本次图纸保存、重开和图元验证通过后，才允许点击“打开CAD图纸”。该按钮通过本机DWG文件关联打开对应图纸。

命令行也可启动界面：

```powershell
.\.venv-demo\Scripts\python.exe app.py
```

可指定`--port 8766`、`--output-root <目录>`，或使用`--no-browser`只启动服务。默认输出在`data/projects/`，API密钥、设计数据、图纸和本机验收截图均不提交Git。

## 澄清、失败与恢复

缺参或歧义时显示具体需要补充的内容，修改输入后重新开始。解析错误、API故障、设计不适用及CAD失败都停止后续步骤；不会自动重试或自动重复出图。

执行中禁止重复提交、打开其他结果图纸和退出程序。页面可以刷新或关闭，后台任务继续执行；重新打开后可在“最近运行”查看最新结果并恢复原输入。用户正在修改的文字不会被后台刷新覆盖。

“检查并恢复CAD”复用已有恢复入口，只处理有归属证据的工具图纸和桥接进程。恢复成功后再点击开始设计，历史失败不会改成成功；如果恢复失败，保留AutoCAD现场及运行记录，不删除日志。该按钮不关闭用户原有图纸。

任务结束后使用“退出程序”结束本机服务。强制结束进程或系统退出后，不会自动重放任务；既有Project State与CAD恢复机制会标记中断或待恢复状态。

## 验收与实现边界

界面用Python标准库HTTP服务和本地静态页面；后台线程执行既有Controller，页面读取SQLite对应运行及标准ToolResult。UI中的项目名称附短运行编号作为project_id，每次执行独立保存，CLI仍可使用原入口。

默认端口避免重复启动，同一输出目录已有RUNNING记录时禁止新任务；页面变更请求要求本机Origin及页面会话令牌。静态路由只提供打包页面，不提供任意文件浏览或密钥读取；打开图纸只接受本次已完成结果、输出根目录内的现存DWG。

后续专业插件可以复用该服务和Controller。当前案例按钮、模板说明、参数表和设计摘要是楼盖演示的呈现部分；未来添加专业可扩展UI描述，不需要改变Controller。

测试结果及未验证边界见[阶段7报告](stages/phase-7.md)。阶段8已整理`v0.1-demo`冻结版本，部署及后续分支约定见[版本说明](releases/v0.1-demo.md)。
